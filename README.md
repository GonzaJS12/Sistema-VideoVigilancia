# Sistema de Videovigilancia Inteligente (SIV IA)

Repositorio del **cliente móvil** del sistema de seguridad basado en visión artificial.
El backend (FastAPI) y el frontend web se desarrollan por separado.

- [`app-movil/`](app-movil): aplicación React Native (Expo, TypeScript, NativeWind).
- [`docs/diseno/`](docs/diseno): capturas del diseño en Figma.

Instrucciones de ejecución en [`app-movil/README.md`](app-movil/README.md).
